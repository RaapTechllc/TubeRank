# Prompts

Reusable prompts invoked with `@prompt-name`.

## Workflow Prompts

| Prompt | Purpose |
|--------|---------|
| `@create-prd` | Create product requirement document |
| `@create-plan` | Create implementation plan from PRD |
| `@implement-plan` | Execute a plan with validation |
| `@prime` | Initialize session context |
| `@execute` | Execute current task |
| `@next-task` | Get next task from PLAN.md |

## Review Prompts

| Prompt | Purpose |
|--------|---------|
| `@code-review` | Review code for issues |
| `@security-audit` | Security vulnerability scan |
| `@a11y-audit` | Accessibility audit |
| `@ui-review` | UI/UX review |
| `@test-coverage` | Analyze test coverage |

## Self-Improvement

| Prompt | Purpose |
|--------|---------|
| `@reflect` | Analyze session, capture learnings |
| `@self-reflect` | RBT analysis (Roses, Buds, Thorns) |
| `@rca` | Root cause analysis for failures |

## Utility Prompts

| Prompt | Purpose |
|--------|---------|
| `@workflow-status` | Check current workflow status |
| `@deploy-checklist` | Pre-deployment checklist |
| `@responsive-check` | Check responsive design |
| `@db-optimize` | Database optimization suggestions |
